Conectar la institución

Conexión configurada para UEGIR-Laboratorio. Las tablas ya están instaladas: no vuelvas a ejecutar el SQL de instalación. Falta crear y autorizar las cuentas de técnicos y publicar ambos HTML juntos.

Guía de usuarios y SQL de referencia (ya instalado)
  1. Crea un proyecto dedicado en Supabase. En SQL Editor ejecuta el script de abajo una sola vez.
  2. En Authentication → Users crea los usuarios de los técnicos. Copia el UUID de cada uno y ejecuta: insert into public.tecnicos(id) values ('UUID_DEL_USUARIO'); Solo estas cuentas tendrán acceso.
  3. Desde Connect copia la URL del proyecto y la clave pública sb_publishable_.... Nunca uses una clave secret o service_role.
  4. Pega los valores aquí. En el panel pulsa “Descargar archivos configurados” y publica juntos los dos archivos descargados en un sitio HTTPS.
  5. Inicia sesión en cada navegador con una cuenta autorizada. Genera las etiquetas desde el sitio publicado.

Se requiere internet y un proyecto Supabase activo. No necesitas programar un servidor propio. Los datos locales anteriores se conservan en su navegador; puedes migrarlos con el botón del panel.
